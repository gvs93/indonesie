Configuration requise

Cette app a besoin de son backend Google Apps Script pour partager les données avec le groupe.

  1. Déploie le fichier Code.gs en application web (voir README.md).
  2. Copie l'URL qui finit par /exec.
  3. Ouvre index.html, et remplace la valeur de API_URL par cette URL.
  4. Recharge la page.
